# Shortcut to Size PWA

Henkilökohtainen offline-first treeniloki Jim Stoppanin **Shortcut to Size** -ohjelmaan (12 viikkoa, mikroperiodisaatio).

## Käynnistys

```bash
npm install
npm run dev
```

## Build / deploy (Vercel, Netlify, Poke-botti)

```bash
npm install
npm run build
```

Julkaise `dist/`-kansio statiikkana. Build-komento: `npm run build`, output: `dist`.

Puhelimella: avaa URL → Asenna sovellus / Lisää Koti-valikkoon.

## Ominaisuudet

- 3 vaihetta × 4 mikroviikkoa (12–15 → 9–11 → 6–8 → 3–5)
- 4-päivän split Ma/Ti/To/Pe
- Settiloki, painojen siirto viikkojen välillä, rest-timer
- Liikeanimaatiot + viikkojen esikatselu
- Offline PWA, export/import JSON
